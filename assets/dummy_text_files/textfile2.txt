Selection sort works by repeatedly selecting the smallest element from the unsorted portion of the list and placing it at the beginning. Unlike bubble sort it performs fewer swaps. However it still involves multiple comparisons across the list. The algorithm divides the array into a sorted and an unsorted section. It continues selecting the minimum until the entire list becomes sorted. Its time complexity is O(n²) for all cases because comparisons always run fully. Selection sort is in-place but not stable. It is simple to understand but not suitable for large datasets. It is mainly used for teaching or very small lists.

Heap sort uses a binary heap data structure to sort elements efficiently. It first converts the list into a max heap where the largest element moves to the root. Then it swaps the root with the last element and reduces the heap size. This process continues until the entire array becomes sorted. Heap sort guarantees a time complexity of O(n log n) for all cases. It works in-place but is not stable. It is widely used when memory usage must remain low and consistent. Although not as fast as quick sort in practice it is predictable and reliable.
