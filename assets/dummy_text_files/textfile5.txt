Quick sort is another divide and conquer algorithm but unlike merge sort it partitions the list around a pivot element. Items smaller than the pivot go to one side and larger items go to the other side. It then recursively sorts the partitions. Quick sort is very fast in practice with an average time complexity of O(n log n). However the worst case is O(n²) which occurs when the pivot selection is poor. The algorithm is not stable but it works in-place. Many libraries use optimized variants of quick sort for fast performance.

Heap sort uses a binary heap data structure to sort elements efficiently. It first converts the list into a max heap where the largest element moves to the root. Then it swaps the root with the last element and reduces the heap size. This process continues until the entire array becomes sorted. Heap sort guarantees a time complexity of O(n log n) for all cases. It works in-place but is not stable. It is widely used when memory usage must remain low and consistent. Although not as fast as quick sort in practice it is predictable and reliable.
